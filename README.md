# Zini vai mini

Pilna nometnes viktorinas lietotne ar speļu redaktoru, vaditaja paneli un sinhronizetu projektora skatu.

## Tehnologijas

- Java 21 un Spring Boot 4.1
- Angular 22
- PostgreSQL
- Clerk autentifikacija
- Bulma dizaina pamats

Projekts tiek aktivi izstradats. Pilna palaisanas un Render izvietosanas instrukcija tiks pievienota pirms pirmas relizes.
